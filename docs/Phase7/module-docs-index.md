# Module Documentation Index (Phase 7 §6.4)

This index is generated by listing the real controller folders under `PlantSafety.Api\` (266
`*V1Controller.cs` files at the time of writing) — it is not hand-authored or invented. Each
bounded context maps 1:1 to the corresponding `PlantSafety.Application\<Area>\` and (for
tenant-facing modules) `PlantSafety.UI\Modules\<Area>\` folders. For the full 66-module UI
navigation taxonomy (9 sections + Platform Tools), see
`PlantSafety.UI\Routing\ModuleRouteRegistry.cs`, which is the single source of truth for
sidebar/menu grouping.

## Non-goals / explicitly out of scope this session

- Thresholds and Routing Rules editors remain out of scope for `/modules/operations-configuration`
  — no backing SQL Server tables exist (documented in that page's own header comment).
- A dedicated Enterprise Event Mesh (Outbox/DeadLetterEvents) visual viewer was not built this
  session; the Support Console links out to the existing Enterprise Fabric dashboard
  (`/modules/enterprise-fabric`) and the cross-database Audit Viewer
  (`/modules/operations-audit-viewer`) instead of duplicating dashboard infrastructure.
